    Frases da API

    Para o outro app escrever na tela

    1. Onde: o outro app precisa rodar neste mesmo computador e chamar POST http://127.0.0.1:8765/api/v1/texto
    2. O que mandar: só o texto. {"texto": "A dúvida é o começo da sabedoria."}
      Opcional: "cena" (nome de uma cena daqui), "modo" (palavra ou inteira), "segundos".
    3. O que acontece: o rodízio pausa, a frase aparece do jeito da cena (letra, brilho, páginas) e, passado o tempo acima, o rodízio volta. Uma frase nova substitui a anterior.
    4. Se a tela estiver fora: resposta 503; é só tentar de novo, o VFD Studio reconecta sozinho.
